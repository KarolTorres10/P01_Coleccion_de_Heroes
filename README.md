***Proyecto:*** Colección de Heroes

Es un proyecto académico para la materia de Desarrollo de Aplicaciones Web, donde se realiza una colección de personajes (en este caso, personajes del videojuego Marvel Rivals). La pagina fue desarrollada con HTML5, JavaScript, CSS y el framework de Bulma, además, de usar herramientas como JSON y LocalStorage para la conversión y guardado de datos/información de forma interna, aun si el sitio web ha sido recargado o se ha cerrado.



***URL GitHub Pages:*** https://karoltorres10.github.io/P01\_Coleccion\_de\_Heroes/



***Funcionalidades implementadas:*** La pagina web cuenta con una barra de búsqueda donde se filtran los personajes según la búsqueda del usuario en tiempo real, si la búsqueda no coincide con ningún personaje se muestra un aviso que le notifica de esto. Cuenta con un botón para agregar personajes, el cual al momento de darle clic abrirá un formulario con los campos a llenar para añadir al nuevo personaje. Al dar clic sobre las cards de cada héroe se abrirá una pestaña en overlay con los detalles del héroe seleccionado. El mismo formulario para añadir personajes se encontrara en el botón "editar" dentro de los detalles de cada héroe, solo que en este caso aparecerá el formulario lleno con los datos del héroe seleccionado; el usuario será capaz de editar estos datos y guardar las modificaciones que realizo. Dentro de la pestaña de detalles también aparecerá un botón para eliminar al héroe seleccionado; si el usuario da clic sobre el botón "eliminar" aparecerá un mensaje de confirmación que si el usuario decide confirmar, el personaje seleccionado será eliminado de la pagina web (Todos los personajes agregados que posteriormente sean eliminados no se podrán recuperar, los únicos personajes capaces de ser recuperados serán los 8 personajes originales de la pagina web). Dentro del Navbar a un lado del botón "Agregar Heroe" se encontrara un botón de "restablecer", dicho botón eliminara los datos almacenados en el localstorage, por lo que todos los cambios y personajes agregados serán eliminados al momento de dar clic al botón, por lo que permanecerán únicamente los 8 personajes originales de la pagina web.



***Instrucciones de Uso:*** Este proyecto fue creado con fines educativos, por lo que tienes total libertad de probarlo y experimentar con el. Divierte añadiendo tus personajes favoritos dentro de la pagina web!!
